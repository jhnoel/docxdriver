# Generated DOCX core

This directory is the self-contained runtime payload for `docxdriver-pi`.
`docxdriver.js`, its declarations, and `docxdriver_bg.wasm` are generated by the
Rust `docxdriver-wasm` build. They are ignored by Git. `npm run build` generates
them and copies the same runtime into both npm packages. Rust and `wasm-pack`
are required when building from a checkout.

The extension intentionally loads these files by a relative URL; it does not
depend on a sibling checkout or on the separate `docxdriver` npm package at
runtime. The shared build script keeps this directory in sync with
`packages/docxdriver/wasm/`.
